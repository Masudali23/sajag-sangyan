HOSTED SERVICES AND APIS

- Google Gemini API (Gemini 3.5 Flash-Lite): optional AI review. It runs only after the user gives permission for that message. Personal details are masked first (best effort). Under Google's unpaid-service terms, inputs and outputs may be used to improve Google's products and may be seen by human reviewers. API keys stay on the server and are never shipped in the app.
- Supabase: email and password sign-in, one-time email verification and opt-in notebook backup. Each user can access only their own records.
- Vercel: hosting for the website and API.
- OpenAI API: an optional server adapter exists in the code but is not enabled in this release.
- Device speech services (Android SpeechRecognizer and TextToSpeech, browser Web Speech API): Speak it and Listen. Available languages and voices depend on the device, and some services process audio or text online. Sajag does not store microphone audio. Voice notes forwarded from chat apps are not imported.


CONTENT AND DATA

- Official guidance: Sajag's educational explanations are original summaries that link to public SEBI, RBI and Government of India publications. They are not official translations, and no regulator endorsement is claimed.
- Bengali content is in beta, pending native-speaker review.
- Retrieval (RAG) uses a local BM25 index over 22 curated guidance cards. It does not search the web, and it does not verify senders, registrations or links.
- The pattern model was trained on the project's synthetic development examples, never on user messages. Selected public SMS datasets were used only during development and evaluation, under their own attribution and licence terms.
- The server keeps a short-lived memory cache (up to six hours) of text-free review results: warning categories, positions and guidance identifiers, never the message text. Nothing is written to disk.
- Saving and cloud backup happen only when the user chooses. The notebook stored on the device is not encrypted.
