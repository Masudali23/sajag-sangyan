# Sajag 3D icon kit

128×128 WebP renders of [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji) 3D assets (MIT, see `LICENSE-fluentui-emoji.txt`). `manifest.json` maps each Sajag id to its source emoji and intended use. These icons are decorative: render them with `alt=""` (or `aria-hidden`) next to a visible text label, and add `/emoji/*.webp` to the offline precache allowlist if the shell uses them.
